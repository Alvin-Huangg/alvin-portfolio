# Alvin Huang — Portfolio

Built with Next.js 14, Tailwind CSS, Sanity CMS, Spotify API, and Supabase.

## Setup

### 1. Install dependencies
```bash
npm install
```

### 2. Environment variables
Copy `.env.local.example` to `.env.local` and fill in your values:
```bash
cp .env.local.example .env.local
```

### 3. Run locally
```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000)

### 4. Deploy to Vercel
Push to GitHub, then import the repo in Vercel. Add all env variables in Vercel dashboard.

## Stack
- **Next.js 14** — App Router
- **Tailwind CSS** — styling
- **Sanity.io** — blog CMS
- **Spotify API** — now playing + music data
- **Supabase** — notes storage
- **Vercel** — hosting
